# HFT Ops Interview Preparation

These are my self-directed prep notes for an interview for a high-frequency-trading operations role. The document is split into three parts: probability theory, brainteasers, and code.

The probability part runs from combinatorics through probability, expected
value, conditional probability and Bayes, named distributions, and Markov
chains. 

Each topic pairs a short theory subsection with a set of worked problems. Explanations aim to be intuitive rather than mathematically complete.

Brainteasers open with a strategy section on framing and standard reductions,
then a set of problems. The code part collects recurring patterns for
SQL (PostgreSQL), DSA in Python (paradigms, recursion and memoization, heaps,
sliding window), and pandas, each closing with a command reference.

Problem solutions are toggleable: `\showsolutionstrue` prints them for review,
`\showsolutionsfalse` hides them for self-quizzing before a recompile.
